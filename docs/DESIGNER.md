# Обычный конструктор WinForms

Откройте решение в Visual Studio 2022 и выполните **Сборка → Перестроить решение**.

- **`Forms/MainForm.cs` → Shift+F7** — вся форма: шапка, кнопка администратора, площадка с автоматами, нижняя подпись.
- **`Forms/CoffeeMachineControl.cs` → Shift+F7** — сам автомат с тремя готовыми блоками: выбор кофе, оплата, выдача.

Это стандартные дизайнеры Form и UserControl. Специального Designer SDK, собственного масштабировщика и копирования координат больше нет. Чтобы редактировать внутренности UserControl, открывайте его собственный конструктор — обычное поведение WinForms.

## Как передвигать и менять размеры

В конструкторе автомата выберите `modulesLayout` через **Вид → Другие окна → Структура документа**. Это обычный `TableLayoutPanel`. Внутри находятся `selectionModule` и `paymentModule`.

- Для перестановки перенесите блок в другую ячейку. При обмене можно временно вынести один блок из таблицы.
- **F4 → ColumnStyles** задаёт ширину столбцов: исходно 70% для меню и 30% для оплаты. Если поменяли блоки местами, поменяйте и доли столбцов.
- `machineLayout` задаёт вертикальные разделы: заголовок, основная часть, сообщение, выдача, кнопки администратора. **RowStyles** задаёт их высоту.
- `Dock = Fill` заставляет модуль занимать свою ячейку; `Margin` задаёт отступы.
- Для свободного расположения в обычной панели используйте `Dock = None`, затем `Location`, `Size` и `Anchor`. В таком случае привязки настраивает разработчик.

Сохраните форму и запустите приложение. Раскладка `CoffeeMachineControl.Designer.cs` используется всеми экземплярами автомата.

## Внутри модулей

| Конструктор | Что редактировать |
|---|---|
| `Modules/CoffeeSelectionControl.cs` | Меню и параметры заказа |
| `Modules/BeverageMenuControl.cs` | Карточки напитков, фильтры, страницы |
| `Modules/OrderOptionsControl.cs` | Сахар, молоко, сироп, кнопка перехода к оплате |
| `Modules/PaymentControl.cs` | Карту, дисплей, наличные и оплату |
| `Modules/DispensingControl.cs` | Приготовление, получение напитка, сдачу |

## Адаптивность

WinForms меняет размеры через `Dock`, `Anchor` и процентные строки/столбцы таблиц. Самописного пересчёта шрифтов и координат нет. Шрифты сохраняют читаемый размер; DPI обрабатывается главным окном. При недостатке места декоративный заголовок меню скрывается, чтобы освободить место напиткам.

У автомата есть минимальный размер 600×680 при 96 DPI. Ниже него невозможно сохранить читаемость всех элементов: маленькое окно прокручивает площадку целиком. Несколько автоматов стоят рядом. Это адаптивная раскладка с минимальным размером, а не уменьшение интерфейса как картинки.

Покупатель не передвигает блоки. Раскладка хранится в исходниках Designer, настройки напитков — в JSON. Модули показывают состояние и передают события; `CoffeeMachineControl` связывает события с прежней моделью покупки.

## Проверки

Проверка логики: `dotnet run --project CoffeeMachineApp.Tests`.

Проверка интерфейса **на Windows**: `dotnet run --project CoffeeMachineApp.UiTests`. Она проверяет границы модулей при разных размерах, перестановку ячеек, постоянство размера шрифтов и два автомата. Снимок окна сохраняется в `artifacts/ui/main-form.png`. В Linux этот проект можно собрать, но нельзя запустить; проверку Visual Studio Designer он не заменяет.

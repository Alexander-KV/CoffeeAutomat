# CoffeeAutomat / BEAN & CUP

Симулятор кофейных автоматов на **C# и Windows Forms (.NET 8)**: независимые автоматы рядом, меню и новые рецепты через админ-панель, сохранение настроек в JSON.

Откройте `CoffeeAutomat.sln` в Visual Studio 2022 и запустите проект `CoffeeMachineApp`.

[Инструкция по запуску, устройству классов и проверкам](CoffeeMachineApp2/README.md).
